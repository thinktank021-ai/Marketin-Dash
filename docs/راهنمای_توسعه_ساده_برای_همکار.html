راهنمای ساده توسعه داشبورد با هوش مصنوعی و گیت‌هاب

ویژه همکاران گرامی (بدون نیاز به هیچ‌گونه پیش‌زمینه برنامه‌نویسی)

🎯 مقدمه: ما قرار است چه‌کار کنیم؟

خیلی خوش آمدید! در این فرآیند شما اصلاً نیازی ندارید که کدنویسی بلد باشید یا دستورات ترمینال تایپ کنید. شما در نقش «مدیر محصول و ناظر» هستید و ChatGPT برنامه‌نویس اختصاصی شما خواهد بود.

شما با استفاده از این راهنما یاد می‌گیرید که چگونه با چند کلیک ساده در یک نرم‌افزار گرافیکی، وظایف را به هوش مصنوعی بسپارید و کدهای آن را مستقیماً به سایت اصلی منتقل کنید.

⚠️ چرا چت قبلی شما بعد از یک هفته قاطی کرد و خراب شد؟
هوش مصنوعی مثل انسانی است که اگر یک هفته مداوم در یک اتاق با او صحبت کنید، خسته می‌شود، حرف‌های روز اول را فراموش می‌کند و چون حافظه‌اش پر شده شروع به «حدس زدن‌های اشتباه و دروغ گفتن» (مثل اختراع دیتابیس‌های موقت D1) می‌کند!

🔑 قانون طلایی: برای هر کار جدید، یک چت کاملاً نو (New Chat) در ChatGPT باز کنید و وقتی آن کار تمام شد، آن چت را ببندید.

🛠️ مرحله ۱: آماده‌سازی اولیه (فقط یک‌بار)

برای اینکه هیچ دستور انگلیسی و کدی تایپ نکنید، از نرم‌افزار رسمی و رایگان گیت‌هاب استفاده می‌کنیم:

۱ دانلود و نصب نرم‌افزار GitHub Desktop

این برنامه تمام امکانات گیت‌هاب را به دکمه‌های ساده تبدیل کرده است:

دانلود GitHub Desktop (کلیک کنید)

پس از نصب، با همان اکانت گیت‌هاب خود (thinktank021-ai) لاگین کنید (Sign In).

۲ آوردن پروژه روی لپ‌تاپ (Clone)

  1. در برنامه GitHub Desktop، از منوی بالا روی File > Clone Repository کلیک کنید.
  2. به تب GitHub.com بروید و پروژه را انتخاب کنید:
    am333ni7y/ziarati-marketing-dashboard
  3. روی دکمه آبی‌رنگ Clone کلیک کنید. پوشه پروژه ظرف چند ثانیه روی لپ‌تاپ شما آماده می‌شود.

🔄 مرحله ۲: چرخه ۴ قدمی انجام هر کار جدید (روال روزمره)

۱. دکمه دریافت تغییرات (Fetch) ⬅️ ۲. ساخت شاخه نو (Branch) ⬅️ ۳. سفارش کار در چت نو ChatGPT ⬅️ ۴. دکمه Commit و Push

۱ گام اول: دریافت آخرین تغییرات روز

هر بار که می‌خواهید کار جدیدی شروع کنید، برنامه GitHub Desktop را باز کنید و بالا سمت راست دکمه Fetch origin (یا Pull origin) را بزنید تا مطمئن شوید کدهای شما کاملاً به‌روز است.

۲ گام دوم: ساخت شاخه کار جدید (New Branch)

برای اینکه کارهای شما با کار بقیه همکاران تداخل نکند، برای هر کار یک شاخه جداگانه می‌سازیم:

  1. در بالای نرم‌افزار روی گزینه Current Branch کلیک کنید.
  2. دکمه New Branch را بزنید.
  3. یک اسم انگلیسی ساده برای کارتان بنویسید (مثلاً: add-phone-search یا fix-header-style).
  4. دکمه آبی Create Branch را بزنید.

۳ گام سوم: سفارش کار به ChatGPT (در چت جدید)

وارد ChatGPT شوید، دکمه New Chat را بزنید و دقیقاً متن داخل کادر زیر را کپی کنید و در اولین پیام برای او بفرستید:

📋 متن شناسنامه پروژه (کپی کنید و در چت اول بفرستید) سلام! من دارم روی پروژه «داشبورد مدیریت بازاریابی دفاتر زیارتی و گردشگری (دنیاگردی و نوآوران)» کار می‌کنم. این پروژه با Next.js 16 و React 19 و TypeScript توسعه داده شده و دارای دیتابیس فعال با داده‌های واقعی است. قبل از نوشتن هر کدی، این اصول اساسی و حیاتی پروژه را کاملاً رعایت کن: ۱. دیتابیس پروژه یک فایل فیزیکی SQLite پایدار روی سرور cPanel است (در حالت WAL). به هیچ وجه فرض نکن این پروژه روی کلادفلر D1 یا چیزهای موقت است. ۲. اصل عدم صفر شدن (Anti-Zeroing): در صورت خطای اتصال به شیت یا گوگل ادز، اعداد داشبورد نباید صفر شوند و باید آخرین داده کش شده را نشان دهند. ۳. تفکیک کامل شعب: همه جداول بر اساس فیلد brand_id برای دو دفتر «دنیاگردی» و «نوآوران راه سپید» تفکیک شده‌اند. دیتای این دو نباید با هم ترکیب شود. ۴. هیچ فایل دیتابیسی را ریست یا بازنویسی نکن. کاری که الان از تو می‌خواهم این است: [اینجا تسک و تغییر مورد نظرتان را به زبان ساده فارسی بنویسید] لطفاً دقیقاً بگو کدام فایل باید تغییر کند و کل کدهای اصلاح شده را به من تحویل بده.

وقتی هوش مصنوعی کدهای جدید را تحویل داد:

  1. در GitHub Desktop از منوی بالا روی Repository > Show in Finder (در ویندوز: Show in Explorer) کلیک کنید تا پوشه فایل‌های پروژه باز شود.
  2. فایلی که هوش مصنوعی مشخص کرده را با هر ویرایشگری باز کرده، کدهای جدید را داخل آن ذخیره (Save) کنید.

⚡ روش فوق‌العاده سریع: مشاهده زنده تغییرات روی سیستم شما (Localhost Live Preview)

برای اینکه در طراحی ظاهر و ریسپانسیو موبایل «کورکورانه تغییر ندهید» و هر تغییری را همان ثانیه به صورت زنده در مرورگر ببینید:

🚀 اجرای لوکال‌هاست با ۱ کلیک موس (بدون کدنویسی)

در پوشه پروژه، یک فایل جادویی برای شما قرار داده‌ایم:

  • اگر لپ‌تاپ شما مک (macOS) است: روی فایل run-local.command دو بار کلیک کنید.
  • اگر لپ‌تاپ شما ویندوز (Windows) است: روی فایل run-local.bat دو بار کلیک کنید.

با همین یک کلیک:

  1. دیتابیس تستی هر دو دفتر «دنیاگردی» و «نوآوران» با تمام بودجه‌ها خودکار لود می‌شود.
  2. مرورگر شما باز شده و داشبورد روی آدرس http://localhost:3000 نمایش داده می‌شود.
  3. مشاهده آنی (Hot-Reload): هر کدی را ذخیره کنید، در کسری از ثانیه بدون حتی رفرش دستی، صفحه تغییرات را زنده نشان می‌دهد!
  4. تست ریسپانسیو موبایل: در مرورگر کلید F12 کیبورد را بزنید و روی آیکون موبایل کلیک کنید تا ببینید داشبورد در گوشی چگونه نمایش داده می‌شود.

🤖 اتصال مستقیم اکانت گیت‌هاب به ChatGPT Plus (اختیاری ولی فوق‌العاده سریع)

اگر اشتراک ChatGPT Plus دارید، می‌توانید گیت‌هاب را مستقیم به چت وصل کنید تا خود هوش مصنوعی فایل‌ها را بخواند و بنویسد:

  1. در ChatGPT روی عکس پروفایل خود کلیک کرده و به Settings > Connected Apps بروید (یا در کادر چت علامت گیره 📎 یا منشن @ را بزنید).
  2. گزینه GitHub را انتخاب کرده و دسترسی به ریپازیتوری am333ni7y/ziarati-marketing-dashboard را تایید کنید.
  3. حالا در چت کافیست به فارسی بگویید:
    «فایل app/dashboard-client.tsx را بخوان و فونت‌های بخش موبایل را بهینه‌تر کن و برایم روی یک برنچ جدید ذخیره کن.»

۴ گام چهارم: فرستادن کار به گیت‌هاب (با ۲ کلیک)

وقتی در لوکال هاست تست گرفتید و از ظاهر و کارکرد ۱۰۰٪ راضی بودید:

  1. به نرم‌افزار GitHub Desktop برگردید؛ می‌بینید که فایل تغییریافته را با رنگ سبز نشان داده است.
  2. در کادر کوچک پایین سمت چپ، یک توضیح یک خطی بنویسید (مثلاً: بهینه‌سازی ریسپانسیو موبایل).
  3. روی دکمه آبی‌رنگ Commit to ... کلیک کنید.
  4. سپس در بالای صفحه روی دکمه آبی‌رنگ Publish Branch (یا Push origin) کلیک کنید.
🎉 تبریک! کار شما بدون نوشتن حتی ۱ خط دستور، وارد گیت‌هاب شد.

🚀 مرحله ۳: پیوند کار به نسخه اصلی (Pull Request)

پس از زدن دکمه Push، در بالای همان نرم‌افزار GitHub Desktop یک دکمه بزرگ به نام Create Pull Request ظاهر می‌شود:

  1. روی آن کلیک کنید تا صفحه گیت‌هاب در مرورگر باز شود.
  2. روی دکمه سبز رنگ Create Pull Request کلیک کنید.
  3. تمام! مدیر فنی (امین) با یک کلیک کار شما را بازبینی و تایید می‌کند و تغییرات بلافاصله روی سایت لایو می‌نشیند.

⛔ خطوط قرمزی که هوش مصنوعی هرگز نباید انجام دهد:

  • دست زدن به دیتابیس: اگر چت‌جی‌پی‌تی گفت فایلی با پسوند .sqlite را پاک کنید، بلافاصله بگویید «خیر، دیتابیس سرور نباید دست بخورد».
  • حرف زدن از Cloudflare D1: به او یادآوری کنید دیتابیس روی سرور cPanel و از نوع SQLite پایدار است.
  • حذف دفتر نوآوران یا دنیاگردی: تمام قابلیت‌ها باید همزمان برای هر دو دفتر فعال بمانند.
